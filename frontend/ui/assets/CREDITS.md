# Astronomy artwork

## Lunar surface

[moon-surface.jpg](./moon-surface.jpg) is the 2048 × 1024 color map from the
[NASA Scientific Visualization Studio CGI Moon Kit](https://svs.gsfc.nasa.gov/4720).
Visualization: Ernie Wright. Source imagery: Lunar Reconnaissance Orbiter Camera
and Lunar Orbiter Laser Altimeter instrument teams. The local file is an unmodified
copy of [lroc_color_2k.jpg](https://svs.gsfc.nasa.gov/vis/a000000/a004700/a004720/lroc_color_2k.jpg).

The map supplies surface detail for illustrative learning-world planets. The
subject worlds and their arrangement are fictional educational navigation.

## Generated artwork

[galaxy-spiral.png](./galaxy-spiral.png) and
[cosmic-deepfield.png](./cosmic-deepfield.png) were generated with the built-in
imagegen tool for Cosmica. The [prompt record](../../../docs/design/IMAGEGEN_PROMPTS.md)
describes their creation. The spiral image is used only for the Languages galaxy;
the remaining foreground celestial forms are procedural three-dimensional volumes.

The cinematic-atlas revision uses [galaxy-spiral-v2.png](./galaxy-spiral-v2.png)
and [cosmic-web-v2.png](./cosmic-web-v2.png), generated with the built-in imagegen
tool on 25 October 2026. The original images are retained. The new spiral has
genuine alpha transparency and is placed within the live scene; the environment
provides distant atmosphere alongside procedural three-dimensional filaments.
These are illustrative astronomical artwork, not an observational dataset or
a physical-scale simulation. The complete prompts and concept are recorded in
[the design record](../../../docs/design/IMAGEGEN_PROMPTS.md).
